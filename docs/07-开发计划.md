## 2. M0 · 技术验证（1 周）

> 目标不是做功能，而是**证伪**。任何一项失败都要立刻调整方案。

| # | 任务 | 产出 | 估时 | 判据 |
|---|---|---|---|---|
| M0-1 | Win32 原生窗口 + 菜单 + 工具栏 + 状态栏 + 分隔条 | demo 程序 | 2 d | 拖动窗口/缩放 DPI 不错位；深浅色跟随系统 |
| M0-2 | Media Foundation 采集 1080p30 | 控制台 + 预览 | 2 d | CPU ≤8%；3 种摄像头均能出图 |
| M0-3 | D3D11 + DXGI Flip + D2D 叠加层 | 预览窗口 | 2 d | 无撕裂；叠加文字清晰；无内存增长 |
| M0-4 | Tesseract 静态链接 + 中文识别 | CLI 工具 | 1 d | A4 300dpi 中文 ≤3s |
| M0-5 | 命名引擎原型 | 单测 | 1 d | 变量渲染 + 校验 + 重名策略全通过 |

**Go/No-Go 判据**

- [ ] 三类摄像头（罗技 / 笔记本内置 / 国产模组）在 MF 下均能出图
- [ ] 预览 CPU 达到 NFR-P-02
- [ ] Tesseract 中文准确率在自建测试集上 ≥90%（验证阶段标准，正式 ≥95%）
- [ ] 原生控件在 125%/150% DPI 下布局正确
- [ ] UI 层代码量估算与实际相符（若 M0-1 超过 3 天，需重新评估 ADR-003）

**失败预案**

| 失败项 | 预案 |
|---|---|
| 原生 UI 开发量失控 | 引入 `winsafe` 降低样板；或仅对复杂面板引入第三方控件封装 |
| MF 兼容性太差 | 提升 DShow 为并列后端（而非兜底），维护两套实现 |
| D3D 叠加层复杂 | 叠加层改用 GDI 双缓冲（性能足够，实现简单） |
| Tesseract 效果不足 | 增加预处理算子；考虑引入 ONNX 版 PaddleOCR（包体 +60MB） |

**目标**：能完成"插摄像头 → 拍照 → 文件出现在磁盘 → 导出 PDF"。

| M1-2 | 采集抽象层 + MF 后端完整实现（枚举/格式/异常） | M0-2 | 4 d |
| M1-3 | DShow 兜底后端 | M1-2 | 3 d |
| M1-4 | 设备热插拔、状态机、错误映射 | M1-2 | 2 d |
| M1-5 | 主界面完整布局与控件绑定 | M0-1 | 3 d |
| M1-6 | 拍照 → 增强 → 原子落盘流程 | M1-5 | 3 d |
| M1-7 | 命名引擎完整实现 + 设置页命名 tab | M0-5 | 3 d |
| M1-8 | 会话模型 + 缩略图列表 + 撤销 | M1-6 | 3 d |
| M1-9 | 自动裁边 + 透视校正 + 纠偏 | M1-6 | 4 d |
| M1-10 | 导出 JPG / PDF | M1-8 | 3 d |
| M1-11 | 配置系统 + 首次运行向导 | M1-7 | 2 d |

> **当前进度（2026-11-07）**：M1-2/M1-4 已完成；M1-5 主布局与设备下拉框可用；
> M1-6 的「拍照 → JPEG 原子落盘」已可用（增强管线待做）；
> M1-7 已提供命名模板、输出目录、重名策略与 JPEG 质量的设置面板及实时示例；
> M1-8 的会话模型、`session.json` 持久化、崩溃恢复、缩略图列表、3 秒撤销、
> 页面删除/查看与新建文档已完成；M1-10 的 JPG/PDF 导出已可用。
> M1-9 的第一版增强管线（自动裁边、纠偏、去阴影、白底净化 + 强度调节）已完成。
> M2-5 的图片导入（JPG/PNG/BMP → JPEG）与系统打印调用已完成。
> M1-3 的 DirectShow 兜底后端已接入：MF 打不开时自动降级，并合并两套设备列表。
> M2-4 的第一版 OCR 已接入：调用本机 Tesseract 5，结果写入同名 `.txt` 并弹窗查看；
> M2-3 的基础编辑已完成：页面旋转 90°、水平镜像、保留原图（`.usbscan/raw/`）并用当前
> 增强设置重新处理选中页；M2-2 的自动透视校正已接入增强管线（内容极值点 + 单应性变换），
> 并新增模态四角点手动校正窗口（拖拽、重置、实时预览，应用后原子写回成品图）。
> OCR 结果改为在模态文本窗口中校对后原子写回 `.txt`，并支持合并导出全部页面文本。
> 批注窗口已加入：手写笔迹/矩形框、四种颜色（含半透明荧光笔）、撤销与清空，应用后扁平化写回。
> PDF 导出支持 A4/US Letter/跟随图片尺寸、自动方向、页边距与适应/填满排版；
> 另外支持导出全部 JPG 与合并导出全部 OCR 文本。
> 连拍（5 张）与定时拍摄（3 秒倒计时）已接入工具栏，可再次点击取消。
> 视图菜单可隐藏/显示左右面板；剪贴板位图可经 `Ctrl+V` 直接导入为新页面。
> `工具 → 设置` 可配置 OCR 语言与 Tesseract 路径并持久化；`文件 → 打开工程` 可切换输出目录。
> `编辑` 菜单支持上移/下移当前页，便于整理多页文档顺序。
> 页面列表已改为最新拍摄置顶；右键缩略图可直接打开、定位、旋转、镜像、裁剪、透视、
> 批注、重新处理、上移/下移、OCR、导出、打印或删除，右侧菜单与主菜单共用同一套命令。
> OCR 结果窗口新增识别行框叠加，可点击定位；拍摄设置可调定时秒数、连拍张数与间隔。
> 单页旋转、裁剪、透视、批注与重新处理支持 `Ctrl+Z` 撤销和 `Ctrl+Y` 重做；
> 右键菜单可把当前页复制为系统剪贴板位图。
> `文件 → 导出 Word (.docx)…` 可把全部页面按顺序导出为每页一图的 Word 文档。
> `文件 → 导入 PDF…` 使用 Windows 自带 PDF 渲染器逐页转成 JPEG，支持多页 PDF。
> `文件 → 打印…` 打开 A4 打印预览，可翻页预览并通过系统原生打印对话框逐页打印。
> `录像` 按钮可录制 Motion-JPEG AVI（最大 1280×720、约 5 fps、无音轨）。
> 已用真实 USB 摄像头验证：MF 预览 1920×1080，手动拍摄、3 秒定时与 5 张连拍均正常落盘。
> 待做：版面分析、捆绑语言模型与可搜索 PDF。

**出口条件**

- [ ] 连续拍 100 张无重名、无 0 字节文件
- [ ] 拍摄中强杀进程，重启后图片完好、会话可恢复
- [ ] 命名规则全部校验用例通过
- [ ] 导出 PDF 中文不乱码

## 9. 完成定义（DoD）

一个任务算"完成"，需同时满足：

1. 代码已合并到 main。
2. 有单元测试或集成测试覆盖（UI 布局类除外）。
3. `clippy -D warnings` 通过。
4. 文档已更新（若涉及行为变更）。
5. 手工验证过：浅色 / 深色 / 高对比度 / 125% DPI。
6. 涉及硬件的改动，至少在 2 台设备上验证。
7. 涉及写盘的改动，验证过"拍摄中强杀进程"场景。
