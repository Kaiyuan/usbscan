## 术语表

| 术语 | 含义 |
|---|---|
| **UVC** | USB Video Class，USB 摄像头通用免驱标准 |
| **MF** | Media Foundation，Windows Vista 起提供的媒体框架，Win10 上是采集首选 |
| **DShow** | DirectShow，更老的采集框架，作为兼容兜底 |
| **边拍边存** | 每次按下快门立即将成品文件写入磁盘，而不是先存内存、导出时再落盘 |
| **配方（Recipe）** | 一组图像增强算子的参数集合，不含像素数据 |
| **会话（Session）** | 一次连续拍摄产生的页面集合及其元数据 |
| **页面（Page）** | 会话中的一张图，包含成品文件路径、配方、批注、拍摄信息 |
| **成品** | 已应用增强配方、可直接使用的图片文件 |
| **原图** | 摄像头输出的原始帧，可选保留用于重新处理 |
| **预览帧** | 未应用完整增强管线的降采样画面，仅用于取景 |
| **符号链接** | 设备在系统内的唯一路径，热插拔后仍可稳定匹配同一设备 |

## 设计基线（不可轻易改动的约定）

1. **平台**：仅 Windows 10 1607+ 与 Windows 11。不兼容 Windows 7 / 8。
2. **界面**：使用 Win32 原生控件，不使用自绘 UI 框架。
3. **采集**：Media Foundation 为主，DirectShow 兜底，不依赖任何厂商 SDK。
4. **存储**：边拍边存，快门即写盘。
5. **OCR**：仅本地 Tesseract，不提供任何云端识别通道。
6. **数据**：零遥测、零后台上报，所有网络行为必须由用户显式触发。
7. **许可**：GPL-3.0-or-later 开源发布，不包含试用期、激活码、序列号等任何授权限制。
