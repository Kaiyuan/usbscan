# 04 · 文件命名规则

> 文档版本：0.3　|　状态：评审中　|　最后更新：2026-11-07
>
> 本文档是"边拍边存"模式下的核心契约，需要精确到字符级。任何实现与本文不符，以本文为准。

---

## 1. 设计目标

1. **拍摄瞬间即确定路径**——用户在按快门之前，就能从状态栏看到文件名。
2. **可预测**——相同输入必得相同输出，不含隐式随机。
3. **可校验**——非法规则在输入时就拦下，不允许拍到一半才报错。
4. **可迁移**——规则是纯文本，可导出、可批量部署、可写进企业文档。
5. **不破坏用户数据**——重名策略默认安全（追加序号），覆盖需二次确认。

---

## 2. 规则模型

一条命名规则由三部分组成：

```toml
[naming]
template      = "扫描_{date:yyyyMMdd}_{time:HHmmss}_{seq:3}"
folder        = "{date:yyyy}/{date:MM}/{date:dd}"
save_on_capture = true
```

| 字段 | 说明 |
|---|---|
| `template` | 主文件名模板，**不含扩展名**；扩展名由导出/保存格式决定 |
| `folder` | 目录模板，相对"输出根目录"；留空表示不分层 |
| `save_on_capture` | 是否边拍边存（v1 固定 `true`，保留字段以便未来扩展） |

最终路径 = `输出根 / folder 渲染结果 / template 渲染结果 . 扩展名`

示例：`D:\扫描\2026\11\07\扫描_20261107_143012_001.jpg`

## 3. 模板语法

### 3.1 基本形式

```
普通文本 {变量} 普通文本 {变量:参数}
```

- `{` `}` 为变量定界符。
- 变量名大小写敏感，全小写。
- 冒号后为参数（格式串或位数）。
- 需要输出字面量 `{` 或 `}` 时，用 `{{` 与 `}}` 转义。

### 3.2 变量总表

| 变量 | 参数 | 含义 | 渲染示例 |
|---|---|---|---|
| `{date}` | 日期格式串，默认 `yyyyMMdd` | 当前日期 | `20261107` |
| `{time}` | 时间格式串，默认 `HHmmss` | 当前时间 | `143012` |
| `{datetime}` | 同 date 格式串 | 日期_时间 | `20261107_143012` |
| `{device}` | 无 | 设备友好名（已消毒） | `Logitech_C920` |
| `{doc}` | 无 | 文档名；未命名时为 `未命名` | `报销单` |
| `{seq}` | 位数，默认 3 | 拍摄序号 | `001`；`{seq:4}`→`0001` |
| `{page}` | 位数，默认 1 | 页面在文档中的序号 | `3` |
| `{pages}` | 无 | 文档总页数 | `12` |
| `{barcode}` | 无 | 识别到的条码内容；无则渲染为空串 | `SN20261107001` |
| `{preset}` | 无 | 当前增强预设名 | `票据` |
| `{width}` | 无 | 图像像素宽 | `3264` |
| `{height}` | 无 | 图像像素高 | `2448` |
| `{dpi}` | 无 | 导出 DPI | `300` |
| `{user}` | 无 | Windows 登录用户名 | `kaiyuan` |
| `{text}` | 无 | 用户在设置中填写的自定义文本 | `合同` |
| `{counter}` | 位数，默认 6 | 持久计数器（跨会话累计） | `000123` |
| `{rand}` | 字符数，默认 6 | 随机小写字母数字 | `a7x2k9` |
| `{uuid}` | 无 | 8 位短 UUID | `3f9a1c2b` |

### 3.3 日期/时间格式串

支持下列占位符（按最长匹配优先）：

| 占位符 | 含义 | 示例 |
|---|---|---|
| `yyyy` | 四位年 | `2026` |
| `yy` | 两位年 | `26` |
| `MM` | 两位月 | `11` |
| `M` | 月 | `11` |
| `dd` | 两位日 | `07` |
| `d` | 日 | `7` |
| `HH` | 24 小时制两位时 | `14` |
| `mm` | 两位分 | `30` |
| `ss` | 两位秒 | `12` |
| `fff` | 毫秒 | `045` |
| `ddd` | 星期缩写（英文） | `Sat` |

其余字符原样输出。**不支持的占位符按字面量处理**，不报错（避免用户被格式串卡住），但校验器给出"未知格式符"警告。

### 3.4 渲染顺序

1. 解析模板为 token 序列（字面量 / 变量）。
2. 用当前上下文（时间、设备、文档、序号）渲染。
3. 对渲染结果做**字符消毒**（见 §5）。
4. 若消毒后为空 → 该段跳过。
5. 拼接扩展名。

> 变量值本身也要消毒。例如设备名 `USB Camera: Front` 中的 `:` 必须替换。

## 4. 序号语义（边拍边存）

这是最容易出错的部分，明确规定如下。

### 4.1 序号来源

| 场景 | `{seq}` 取值 |
|---|---|
| 拍摄 | 会话内的拍摄计数器，每成功落盘 +1 |
| 连续拍摄 | 同上，成功一次 +1；失败不占用 |
| 撤销拍摄 | 默认**回收**该序号（下次拍摄复用），可配置为不回收 |
| 重拍（删除后重拍） | 复用被删除的序号 |
| 外部导入 | 不影响 `{seq}` |
| 导出 PDF | 单文件场景忽略 `{seq}`（使用首次渲染值） |
| 导出图片序列 | 使用 `{page}` 或按导出顺序重新编号（用户可选） |

### 4.2 `{seq}` 与 `{counter}` 的区别

| | `{seq}` | `{counter}` |
|---|---|---|
| 作用域 | 当前会话 | 全局，跨会话 |
| 归零 | 会话结束时归零 | 按策略（每日/每月/从不） |
| 持久化 | 存于会话清单 | 存于配置文件 |
| 典型用途 | 一个文档内的页序 | 全局流水号 |

### 4.3 位数与溢出

- `{seq:3}` → `001`。数值超过位数时**自动加宽**（`1000`），不截断。
- 位数为 0 或未指定 → 不补零（`1`, `2`, `...`）。
- 位数上限 9。

### 4.4 归零策略（会话级）

| 策略 | 行为 |
|---|---|
| 每次会话（默认） | 打开新文档时从起始值重新计数 |
| 每天 | 跨天时重置 |
| 不归零 | 全程序生命周期累加 |
| 每次导出后 | 导出成功后重置 |

## 5. 字符消毒规则

渲染结果的每一段都要经过消毒，顺序如下：

| 步骤 | 规则 |
|---|---|
| 1 | 将 `\ / : * ? " < > \|` 替换为 `_` |
| 2 | 删除控制字符 `0x00`–`0x1F` 与 `0x7F` |
| 3 | 删除文件名开头的空格与句点 |
| 4 | 删除文件名结尾的空格与句点 |
| 5 | 连续下划线压缩为单个（可关闭） |
| 6 | 若结果为空 → 替换为 `unnamed` |
| 7 | 若为 Windows 保留名 → 追加下划线（`CON` → `CON_`） |
| 8 | 截断至 200 字符（按 UTF-16 码元计，避免超 255 字节限制） |

**保留名列表**（不区分大小写，含带扩展名形式）：

```
CON PRN AUX NUL
COM1..COM9  LPT1..LPT9
CLOCK$ CONIN$ CONOUT$
```

> 中文、日文、emoji 均允许（NTFS 支持 UTF-16）。不做 ASCII 化，避免破坏中文用户习惯。

## 6. 校验规则

编辑器内实时校验，每次按键后 50ms 防抖执行。结果三态：合法 / 警告 / 错误。

### 6.1 错误（阻止保存）

| 编号 | 条件 | 提示文案 |
|---|---|---|
| E01 | 模板为空或仅空白 | 命名规则不能为空 |
| E02 | 存在未闭合的 `{` | 变量缺少右花括号 `}` |
| E03 | 存在未知变量 `{xxx}` | 未知变量 `{xxx}`,可用变量见帮助 |
| E04 | 渲染示例中出现非法字符且消毒被关闭 | 规则包含非法字符 |
| E05 | 模板渲染结果长度 > 200 字符 | 文件名过长(最大 200 字符) |
| E06 | 完整路径长度 > 250 字符 | 路径过长,请缩短目录规则 |
| E07 | 目录模板中包含盘符或绝对路径 | 目录规则必须是相对路径 |
| E08 | 目录模板以 `..` 开头或包含 `..\` | 目录规则不能跳出输出根目录 |

### 6.2 警告（允许保存）

| 编号 | 条件 | 提示文案 |
|---|---|---|
| W01 | `{seq}` 后紧跟数字 | 建议在 `{seq}` 后加分隔符,否则序号会与后续数字粘连 |
| W02 | 同时使用 `{seq}` 与 `{page}`,且用于图片序列导出 | 两者可能产生相同结果,建议只保留一个 |
| W03 | 日期格式串含未知占位符 | 未知日期格式符 `zz`,将按字面输出 |
| W04 | 模板未包含任何变量（纯固定名） | 固定文件名会导致重名,已自动启用"追加序号" |
| W05 | 三个预览样例完全相同 | 该规则无法区分不同拍摄,是否继续? |
| W06 | 使用了 `{rand}` 或 `{uuid}` | 文件名不可预测,不利于人工检索 |

### 6.3 校验时机

| 时机 | 行为 |
|---|---|
| 设置页编辑 | 实时校验，错误红框 + 原因 |
| 开始拍摄前 | 若规则非法，弹出一次提示，阻止进入拍摄（不允许"拍到一半失败"） |
| 每次拍摄前 | 静默渲染一次路径；失败则以错误提示并暂停拍摄 |
| 规则变更后 | 仅影响新拍摄，不重命名已有文件 |

## 7. 重名处理

### 7.1 四种策略

| 策略 | 行为 | 默认 |
|---|---|---|
| **追加序号** | `扫描_001.jpg` 存在 → `扫描_001 (2).jpg` → `(3)`… | ✅ |
| 覆盖 | 直接覆盖，需二次确认（单次/本次会话/永久） | |
| 跳过 | 不保存，状态栏提示"已跳过 1 张" | |
| 询问 | 弹原生对话框，最多询问 10 次，之后沿用上次选择 | |

### 7.2 原子占位

边拍边存存在并发风险（连拍 + 后台任务）。落盘流程必须用系统原子语义占位：

```
1. 渲染目标路径
2. 以 FILE_CREATE_NEW (CREATE_NEW) 打开目标文件
   ├─ 成功 → 得到独占句柄,写入
   └─ 失败(已存在) → 按策略处理,回到 1
3. 若写入的是临时文件:写完后 MoveFileEx(MOVEFILE_REPLACE_EXISTING)
```

约束：**不能先 `exist()` 再 `create()`**（TOCTOU 竞态）。

### 7.3 目录创建

- 目录不存在则递归创建（`CreateDirectoryW` 逐级）。
- 创建失败（权限/只读介质）→ 提示并可切换到备用目录。

## 8. 生效时机矩阵

| 动作 | 是否套用命名规则 | 说明 |
|---|---|---|
| 单拍 | ✅ | 立即渲染并落盘 |
| 连拍 | ✅ | 每张独立渲染，序号递增 |
| 定时拍 | ✅ | 同上 |
| 自动翻页 | ✅ | 同上 |
| 导入外部图片 | ❌ | 保留原文件名，复制到会话目录 |
| 导出 PDF | ✅ | 用规则生成 PDF 文件名（忽略 `{seq}`/`{page}` 语义冲突） |
| 导出图片序列 | ✅ | 每页独立渲染，`{seq}` 按导出顺序 |
| 另存为 | ❌ | 使用系统保存对话框 |
| 打印 | ❌ | 不产生文件 |

## 9. 配置与持久化

### 9.1 配置文件片段

```toml
[naming]
template = "扫描_{date:yyyyMMdd}_{time:HHmmss}_{seq:3}"
folder = "{date:yyyy}/{date:MM}/{date:dd}"
text = "合同"                 # {text} 变量的值
seq_start = 1
seq_digits = 3
seq_reset = "session"         # session | daily | never | after_export
seq_recycle_on_undo = true
collision = "append"          # append | overwrite | skip | ask
sanitize = true
max_filename_len = 200
preserve_long_paths = false
counter = 123                 # {counter} 当前值
counter_reset = "never"       # never | daily | monthly
last_reset_date = "2026-11-07"
```

### 9.2 命名预设

```toml
[[naming.presets]]
name = "按日期归档"
template = "{date:yyyyMMdd}_{time:HHmmss}"
folder = "{date:yyyy}/{date:MM}"

[[naming.presets]]
name = "按条码"
template = "{barcode}_{seq:3}"
folder = "{date:yyyyMMdd}"

[[naming.presets]]
name = "证件"
template = "{doc}_{text}_{date:yyyyMMdd}"
folder = "证件/{date:yyyy}"
```

预设可导出为 `.toml` 文件，便于企业批量部署。

### 9.3 文档级覆盖

- 每个文档可临时覆盖规则（存于会话清单）。
- 文档关闭后回到全局规则。
- 界面用"锁"图标提示"本规则仅对当前文档生效"。

## 12. 实现要点

### 12.1 接口

```rust
pub struct NamingRule {
    pub template: String,
    pub folder: String,
}

pub struct NamingContext<'a> {
    pub now: SystemTime,
    pub device: Option<&'a str>,
    pub doc: Option<&'a str>,
    pub barcode: Option<&'a str>,
    pub preset: Option<&'a str>,
    pub text: Option<&'a str>,
    pub seq: u64,
    pub page: Option<u32>,
    pub total: Option<u32>,
    pub width: Option<u32>,
    pub height: Option<u32>,
    pub dpi: Option<u32>,
}

pub struct I18n; // 供错误消息本地化

pub trait NamingEngine {
    /// 静态校验，返回错误与警告
    fn validate(&self, rule: &NamingRule) -> Vec<Diagnostic>;
    /// 渲染单个名字
    fn render(&self, rule: &NamingRule, ctx: &NamingContext) -> Result<Rendered, NamingError>;
    /// 预览 n 个（用于设置页）
    fn preview(&self, rule: &NamingRule, ctx: &NamingContext, n: usize) -> Vec<String>;
    /// 原子占位，处理重名
    fn reserve(&self, dir: &Path, name: &str, policy: Collision) -> Result<PathBuf>;
}
```

### 12.2 性能

- 单次渲染 < 10 µs。
- 预览三次渲染 < 50 µs。
- 校验 < 20 µs（不含 i18n 查表）。

### 12.3 测试要求

必须覆盖：

1. 每个变量的默认参数与自定义参数。
2. 全部日期占位符与未知占位符。
3. 每种非法字符与保留名。
4. 序号位数溢出、归零策略、撤销回收。
5. 重名四种策略的边界（同名 1 次、10 次、并发 2 线程）。
6. 长路径（240/250/260 字符边界）。
7. 中文、emoji、混合文本。
8. 模板中 `{{` `}}` 转义。
9. 空模板、纯空白、只有变量且变量渲染为空。
10. 目录模板包含 `..`、盘符、UNC 路径。
