> 文档版本：0.3　|　状态：评审中　|　最后更新：2026-11-07
>
> 本文描述界面结构与交互。文件名规则相关界面见 [04-命名规则 §10](04-命名规则.md#10-界面规格)。

## 1. 视觉规范

### 1.1 原则

界面是 **Windows 原生控件**，不是"仿 Windows 的自绘控件"。因此：

- 颜色、边框、圆角、阴影全部由系统主题决定，**不硬编码**。
- 字体从 `SystemParametersInfo(SPI_GETNONCLIENTMETRICS)` 读取，跟随用户系统设置。
- 图标使用系统风格的 16/20/24/32 多尺寸 ICO。
- 工具栏功能图标统一使用 [Tabler Icons](https://github.com/tabler/tabler-icons)（MIT），保持 24px 线性风格。
- 唯一允许自定义的是：品牌图标、预览区叠加层、状态指示点。

### 1.2 尺寸（96 DPI 逻辑单位）

| 元素 | 值 |
|---|---|
| 主窗口最小尺寸 | 1024 × 640 |
| 主窗口默认尺寸 | 1280 × 800 |
| 工具栏高度 | 32 |
| 参数条高度 | 30（可折叠） |
| 左缩略图面板宽度 | 180（可拖 140–320） |
| 右属性面板宽度 | 300（可拖 240–420） |
| 状态栏高度 | 24 |
| 分隔条宽度 | 5（拖动热区 8） |
| 控件间距 | 8 / 12 / 16 三档 |
| 缩略图尺寸 | 120 × 150 |

### 1.3 状态色

| 语义 | 颜色来源 |
|---|---|
| 正常/已连接 | `COLOR_HIGHLIGHT` 系（跟随系统强调色） |
| 警告 | 系统橙（`#C77700` 固定，允许在深色主题下提亮） |
| 错误 | 系统红（`#C42B1C`） |
| 禁用 | `COLOR_GRAYTEXT` |

> 高对比度模式下，全部替换为 `COLOR_WINDOWTEXT` / `COLOR_WINDOW`，靠图标形状区分状态。

### 2.1 布局规则

| 区域 | 行为 |
|---|---|
| 工具栏 | 始终可见；窗口宽度 < 1100 时次要按钮收进溢出菜单 |
| 参数条 | 可折叠（点击左侧 ▾），折叠后预览区自动扩展 |
| 左面板 | 可关闭（`视图 → 缩略图`），关闭后预览全宽 |
| 右面板 | 两个分组（增强 / 属性），可折叠；也可整体关闭 |
| 分隔条 | 拖动调整；双击恢复默认宽度 |
| 状态栏 | 4 段：连接状态 / 页数 / **最后保存的文件名** / 磁盘 |

> 当前实现：右面板包含“扫描设置”（输出目录、命名模板、重名策略、JPEG 质量）和“图像增强”（自动裁边、透视校正、纠偏、去阴影、白底净化、强度）。`视图` 菜单可分别隐藏页面面板和右侧面板，预览区自动铺满剩余空间。

### 2.1.3 页面列表

左侧缩略图按 **最新拍摄置顶** 排列，翻页顺序为“最新 → 最旧”。右键任意缩略图会先选中该页并弹出原生上下文菜单：打开、在资源管理器中定位、旋转/镜像、裁剪、四角透视、批注、重新处理增强、上移/下移、OCR 识别/编辑文本、导出当前页 JPG、复制图片、打印、删除。命令与主菜单完全一致。

### 2.1.4 裁剪窗口

`编辑 → 裁剪…`（或右键“裁剪”）打开原生模态窗口：拖动四角手柄调整裁剪范围，拖动框内可整体移动；也可在框外拖出新范围。支持 `Enter` 应用、`Esc` 取消与“重置”。应用后按图片像素裁剪并原子写回成品 JPEG，同时更新会话中的页面尺寸。

### 2.1.1 四角透视校正对话框

`编辑 → 四角透视校正…` 打开原生模态窗口：中央按比例显示当前页，四个角点以圆形手柄绘制在叠加层上，可直接拖动；下方提供“应用 / 重置 / 取消”原生按钮，`Enter` 应用、`Esc` 取消。应用后使用单应性变换生成矩形页面并原子写回成品 JPEG，同时更新会话清单中的页面尺寸。

### 2.1.2 批注窗口

`编辑 → 批注…` 打开原生模态窗口：顶部为“画笔 / 矩形 / 颜色 / 撤销 / 清空”原生按钮，底部为“应用 / 取消”。画布自绘图片与批注，支持四种颜色（红、蓝、黑、半透明黄色荧光笔），`Ctrl+Z` 撤销。应用后批注直接扁平化到成品 JPEG。

### 2.2 边拍边存的视觉反馈

拍摄成功后：

1. 预览区左下角浮出**拍立得缩略图**，300ms 淡入，3 秒淡出。
2. 缩略图上叠加两枚按钮：`撤销`、`查看`。
3. 状态栏第三段更新为刚保存的文件名。
4. 左面板新增一张缩略图并自动滚动到底部。
5. 若写盘失败，浮层变红并显示原因 + `重试`/`换个位置`。

```
                          ┌─────────────────────┐
                          │  ┌───────────────┐  │
                          │  │               │  │
                          │  │   刚拍的照片   │  │
                          │  │               │  │
                          │  └───────────────┘  │
                          │  扫描_…_012.jpg      │
                          │  [ 撤销 ]  [ 查看 ]  │
                          └─────────────────────┘
```

### 2.3 拍摄失败提示条

不弹模态框，用预览区顶部的提示条：

```
┌──────────────────────────────────────────────────────────────────────┐
│ ⚠ 无法保存到 D:\扫描\2026\11\07\ —— 磁盘空间不足（剩余 12 MB）      │
│    [ 清理旧文件 ]  [ 更换目录 ]  [ 重试 ]                        [×] │
└──────────────────────────────────────────────────────────────────────┘
```

> 图像仍在内存中保留 60 秒，用户解决后可重试，**不允许静默丢弃**。

### 3.1 编辑后的保存语义

边拍边存模式下，编辑会**直接改写成品文件**，因此需要明确：

| 操作 | 行为 |
|---|---|
| 调整配方 | 实时预览；点击"应用"后重新渲染并**覆盖**成品文件（先写临时文件再替换） |
| 批注 | 批注以矢量存于 `session.json`；导出/打印时才栅格化；成品图片本身不含批注 |
| 旋转/裁剪 | 写入配方，重新渲染覆盖 |
| 撤销 | 回滚配方，重新渲染覆盖 |
| 关闭文档 | 若有未应用的配方变更，提示"应用并保存 / 放弃" |

> 覆盖前自动保留一份 `.usbscan/history/003_<时间>.jpg`，保留最近 3 个版本，可回滚。

## 6. 设置对话框

左侧 `SysTreeView32` 导航，右侧内容区。分组：常规 / 采集 / 图像处理 / **文件命名** / 快捷键 / 语言 / 关于。

> 当前实现：`工具 → 设置…` 提供 OCR 语言、Tesseract 路径、定时拍摄秒数、连拍张数与连拍间隔，保存后写入 `config.toml` 并立即生效；路径留空时自动搜索 PATH 与常见安装目录。其余分组仍在规划中。

文件命名页见 [04-命名规则 §10.1](04-命名规则.md#101-设置页)。

### 6.0 打印预览

`文件 → 打印…` 打开模态预览窗口：按 A4 比例显示当前页，支持“上一页 / 下一页 / 打印… / 关闭”，左右方向键也可翻页。`打印…` 调用 Windows 原生打印对话框，确认后把整份会话逐页绘制到打印机。

## 8. 长任务与进度

使用 `TaskDialogIndirect` 的进度模式（原生、可最小化）：

```
┌──────────────────────────────────────────────────────────────┐
│  正在导出 PDF                                            [×] │
├──────────────────────────────────────────────────────────────┤
│  正在生成第 8 / 12 页…                                       │
│  ████████████████████░░░░░░░░░░░░░░░░░  67%                  │
│                                                              │
│                                        [ 取消 ]              │
└──────────────────────────────────────────────────────────────┘
```

规则：

- 超过 500ms 的操作展示进度。
- 可实现进度的显示百分比，不可实现的用不确定态进度条。
- 取消必须真正中断，已写出的部分文件要清理。

      │  NoDevice    │ ──────────▶ │   Preview    │
      └──────────────┘ ◀────────── └──────┬───────┘

             │                             │ 继续拍摄

## 11. 键盘与无障碍

- 完整 Tab 顺序：工具栏 → 参数条 → 缩略图列表 → 预览 → 增强面板 → 属性面板 → 状态栏。
- `WS_TABSTOP` + `WS_EX_CONTROLPARENT` 保证原生焦点链。
- 每个控件必须有可访问名称（`SetWindowText` 或 UIA 属性）。
- 自绘预览区实现 `WM_GETOBJECT` 返回 `IRawElementProviderSimple`，向读屏软件报告"摄像头预览画面"及当前状态。
- 状态变化通过 `NotifyWinEvent(EVENT_OBJECT_NAMECHANGE)` 通知。
- 高对比度模式下所有自绘元素使用 `COLOR_WINDOW` / `COLOR_WINDOWTEXT`。
