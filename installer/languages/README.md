# Inno Setup 中文语言文件

这些文件来自 Inno Setup 官方源码仓库的第三方/官方翻译：

- `ChineseSimplified.isl`：简体中文，维护者 Zhenghan Yang，来源
  <https://github.com/jrsoftware/issrc/blob/main/Files/Languages/ChineseSimplified.isl>
- `ChineseTraditional.isl`：繁體中文，维护者 GoneTone，来源
  <https://github.com/jrsoftware/issrc/blob/main/Files/Languages/ChineseTraditional.isl>

Inno Setup 自带的安装包已经包含 English、Deutsch、Français、Italiano、
Español、日本語、한국어，因此这里只补充安装包未附带的中文文件。
